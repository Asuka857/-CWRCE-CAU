# 课程评价与选课建议

## 1. 评价一门课的维度

> 统一用同一套维度评价，方便横向比较。建议每个维度都写，即使写「记不清了」也比空白好。

| 维度 | 说明 |
| --- | --- |
| 课程名称 | 全称 + 课程号 |
| 学分 / 学时 | 投入产出比的关键 |
| 授课老师 | 风格、是否认真、是否给分友好 |
| 考核方式 | 考试 / 论文 / 项目 / 平时分占比 |
| 学到什么 | 真正带走的能力或知识 |
| 推荐指数 | ★★★★★（五档） |
| 一句话点评 | 最有用的一句实话 |

**模板示例**：

```
### 课程名称：XXXXX
- 学分 / 学时：3 / 48
- 授课老师：XXX（风格：偏理论 / 偏实战 / 讲得生动）
- 考核方式：期末考试 60% + 平时作业 40%
- 学到什么：XXXXXXXX
- 推荐指数：★★★★☆
- 一句话点评：XXXXXXXX
```
