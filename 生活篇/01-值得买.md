# 值得买（早买早享受）

> 记录个人觉得值得投入的物品和服务，不代表适合所有人。价格不作固定标注 —— 数码产品价格波动大，请按下面的购买逻辑自行比价。

## 0. 购买逻辑（下单前先看这段）

买任何一件稍贵的数码产品，建议按这几步走，避免花冤枉钱：

1. **先上 B 站搜测评**。搜「品类 + 推荐 / 选购」（如「27 寸显示器 推荐」），看该价位段里几款主流产品的横向对比。
2. **找差异、问为什么**。同一价位为什么有的贵有的便宜？差别在哪 —— 面板、色域、刷新率、防蓝光、做工，每个产品都有自己的特色（卖点）。
3. **对照自己的真实需求**。想清楚买它是为了什么：显示器是码字、修图还是打游戏？需不需要防蓝光？尺寸选 24 寸（桌面小、视距近）还是 27 寸（视野更大、更推荐）？
4. **再决定要不要加钱**。判断「多花的钱换来的提升」是否命中自己的需求 —— 命中就值，不命中就是为用不上的参数买单。
5. **需求说不清就先问 AI**。如果自己也理不清要什么，直接和 AI 对话，把使用场景讲清楚，让它帮你梳理需求和取舍标准，再去看测评。

## 1. AI 编程 / 学习订阅（付费优先）

- **AI 编程助手 / Coding Plan 订阅** — 如果经常写代码、读代码或调试，AI 编程助手可能节省时间。先用免费额度确认它适合自己的工作流，再比较订阅价格、使用限制和隐私条款；学生可查看官方教育优惠是否适用。

## 2. 大屏显示器

- **大屏显示器** — 写代码 / 看论文 / 多窗口对照，外接一块大屏是投入产出比最高的升级之一。选购先定尺寸（24 寸还是 27 寸），再按上面的购买逻辑对照防蓝光、色域、刷新率等特色取舍。

## 3. 人体工学椅

- **人体工学椅** — 长时间久坐的刚需，直接影响腰椎和专注时长。重点看腰托支撑、坐深与靠背调节范围。

## 4. 降噪耳机

- **降噪耳机** — 图书馆 / 宿舍 / 通勤场景下进入「专注模式」的利器。按使用场景选头戴式还是入耳式。

## 5. 平板 + 手写笔

- **平板 + 手写笔** — 看 PDF、做标注、手写笔记，轻量场景替代纸质资料。
